# GoodVision 主程序轻量更新

适用于已安装 GoodVision 主程序的 Windows + Docker Desktop（Linux 容器）机器。
本包更新各路“本机摄像头 / 诊断”，每路独立查看画面、状态、事件、证据，并可独立保存播放缓冲。
浏览器摄像头按钮保留本机预览检查；网络视频分析仍从主控制台统一开始、停止。

1. 在原控制台停止全部分析，等待收尾完成；自动开始分析应关闭。
2. 将 ZIP 解压到任意本地文件夹。无需覆盖原安装目录，也不需要移动模型。
3. 双击 `UPDATE.cmd`。看到 `Update ready` 后刷新原来的控制台地址。
4. 每路卡片上均有“本机摄像头 / 诊断”。重启后可重新连接视频，再手动开始全部分析。

也可在解压目录运行：

```powershell
.\update_harness.ps1
```

`CHECK.cmd` 只检查兼容性。本包不包含回退功能。
`update-state` 只记录安装状态和容器标识，不含密钥。

更新复用现有镜像中的依赖和模型，无需下载或重新安装。精确校验基础镜像与包内文件后才更新。
修正版 diagnostics2 自动识别原 Windows 安装包 `goodvision-harness-windows-20260919-003741`
和本机 `scene-results-20260919-011653` 版本，兼容 Docker 导入后不同的合法镜像标识。
不需要移动原安装目录，也不需要下载本机开发镜像。旧 diagnostics1 更新失败后，直接解压并运行此新版即可。
自动识别实际 Compose 项目和所有通道（含 harness-02），只使用已安装并校验过的基础镜像。
遇到多个兼容项目时，用 `./update_harness.ps1 -Project 项目名` 指定；未知或混合版本会停止。
修正版同时更新原安装目录中的版本和校验记录，之后仍可使用原来的 `start.cmd`，不会重新导入旧镜像。

保留原容器名、端口、环境、配置挂载、网络别名、数据卷和模型卷。切换有短暂重启，运行中的分析必须先停止。
更新时直接替换原容器，不保留旧容器。
本次包含原 Windows 发行版所需的程序差异，不升级依赖、不修改模型、不删除数据卷，也不清理其他 Docker 项目。
原 Compose 使用的镜像标签会指向更新版。

GPU 机器如果只运行 GoodVision Contour，就无需安装本包。只有在 GPU 机器上也安装了 GoodVision 主程序时才使用。
Contour 仍使用既有地址、访问密钥和显存优化版本。
