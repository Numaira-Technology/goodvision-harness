# 运行前敏感度与告警连续性验证

2026-09-10，已更新本机 8080 demo。

## 行为

- 四种行为事件（fight/smoking/fall/weapon）可在控制台启动前独立选择标准或高敏感度。吸烟默认高敏感度，其余默认标准。HTTP/WS 的 `event_sensitivities` 与控制台共用校验和会话快照，运行中不能修改本次配置。
- 吸烟标准档保留“必须认清烟具”的证据要求；高档允许根据可见动作、局部遮挡的小物体和上下文判断。无法识别烟具时描述为疑似动作，框定可见动作区域或参与者，不捏造烟具细节。
- 继续使用完整画面、320 px 事件输入；不做人物裁剪，不改变独立人脸分辨率。
- 行为告警按源帧顺序累计，连续十次有效阴性才解除；阳性重置计数，同一源帧重复/修正结果只计一次，缺失或失败不计阴性。人脸模式按人、按事件独立处理。
- 无人脸模式在第 1–9 次阴性显示待解除告警及进度，不将旧物体框复制到当前阴性画面。原始逐帧 JSON 与证据保持原判定。
- 所有有效迟到观察进入即时结果流，使显示端可以完整累计阴性；迟到阳性另行显示事件通知。最新结果、全画面描述、当前 JSON 和精确画面保持源帧顺序。
- 录像归档仍使用独立的片段合并和结束策略；本次十帧阈值用于控制台与视频中的行为告警状态。
