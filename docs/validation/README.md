## 维护规则

- 新结果直接更新对应专题，写清版本、环境、方法、实际结果和未验证范围；不要每次排障新建一篇日期报告。
- 删除已被替代的过程和结论；只保留影响当前判断的反例、限制及可复核证据。
- 必要的版本、输入、模型清单和汇总放在 `evidence/`，并由专题链接；真实模型回复优先作为测试夹具维护。
- 原始媒体、完整日志、逐次测试输出和临时探针放在忽略目录。操作步骤归入 `guides/`，系统机制归入 `architecture/`。
