# 人物身份与陌生人证据

## 身份归属

`PersonIdentity` 是人物主体持有的身份状态，包含已确认身份、最后直接确认的源时间和私有人脸样本。
绑定到同一主体的人脸短轨迹引用这份状态。没有身体关联的人脸片段暂时持有自己的状态；
同源关联或身份复核证明两者相同后，统一引用主体状态，不只修改 subject_id。

已有轨迹和新建轨迹使用相同的绑定入口。整个源帧处理完成后，再统一投影一次人物身份，
使“已观察到 Frank + 同主体历史陌生人”的结果不依赖对象顺序。投影后的结果才进入身份复核。

原始匹配结果保留在 `observation_status`，例如低分原始结果为 unknown，但已确认主体仍为 known。
`identity_source=track_history` 表示身份连续性，`identity_confirmed_at` 保存真实直接确认时间，
沿用历史不伪装成新一次人脸库匹配。延迟结果不能继承其源时间之后才建立的身份。

连续高质量冲突仍可明确重置身份；删除登记身份、换跟踪 epoch 仍使旧身份失效。
晚关联的 face-only 轨迹也参与 epoch 清理，不能从已退休主体带回姓名。

## 证据交付

人脸分类、主体关联修订、归档入口共用 `stranger_evidence`：

| 输入 | 证据含义 |
| --- | --- |
| 当帧观察到、已知身份 | 非陌生人 |
| 当帧可用人脸、实际未匹配 | 陌生人候选证据，仍需既有身份复核与 N 帧规则 |
| held 历史人脸、沿用的 unknown、不可用人脸 | 没有新增陌生人证据 |

关联修订同时修订人物对象和判断结果；不能只改 subject_id，留下旧陌生人判断。
修订后的归档源观测替换原观测，删除过期的阳性记录，并持久化这一替换。

归档使用的 `confirmed_at` 边界现在表示“通过该源时间已解析为已知身份”。
直接匹配，或携带 `identity_confirmed_at` 的主体连续性观测，可以推进这一边界；
held 显示记录和缺少主体确认来源的旧 track_history 不能推进。边界以后的真实 unknown
既不会被旧身份豁免，也不会被写成 known/Frank。现有事件结束规则保持不变。
