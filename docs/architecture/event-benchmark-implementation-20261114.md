# 可恢复的事件评测批次

基线：main `31e675f0334a630bec3886217671fcc273d7afb3`。

## 解决的问题

单次运行入口不足以管理验证、阈值冻结和十轮正式测试：进程中断后容易重复发送
已经成功的请求，也容易丢失累计重试次数或把未完成结果算作完整一轮。
本实现增加固定实验矩阵和持久化恢复，所有结果保留原始响应与证据哈希。

入口与配置字段见 [BATCH.md](../../tools/unified_benchmark/BATCH.md)。
`batch.example.json` 是待填写预算和路径的模板，不是已授权的运行配置。

## 固定评测范围

每个模型先验证一次：34 段视频 / 44 题，包括原 24 题和现有翻包补充 20 题。
正式测试固定 192 段视频 / 202 题，验证不计入十轮。当前选定九行如下：

| 配置 | alias | 正式轮数 |
|---|---|---:|
| Qwen3-VL-8B（API） | `qwen8b` | 10 |
| Gemini 2.5 Flash off | `gemini25_off` | 10 |
| Qwen235B | `qwen235b` | 10 |
| Luna | `luna` | 10 |
| CLIP L/14 | `clip` | 10 |
| SigLIP2 B/16 | `siglip2` | 10 |
| VideoJev-4B | `videojev` | 10 |
| Decision3 Nano | `decision3` | 10 |
| Qwen3-VL-8B / R2 vLLM | `qwen8b_r2_vllm` | 10 |

本批次排除 Gemini 2.5 Flash low、Gemini 3.8 Flash low、Gemini Decision 1、
Llama4 Maverick 和 Qwen8B / R2 Transformers。代码支持的其他 profile 不会自动入选。

Astra / Hydrogen low、medium 是独立验证模式的候选，不包含在这九行中。
它们使用 `event-benchmark-validation-v1`、`repeats=0`，每个选定配置只运行一次
validation44。此模式不准备或启动正式测试，不自动转入十轮。
Astra 不发送不受支持的 temperature 参数；Hydrogen 固定 temperature=1。
每对配置的请求只在 effort 上不同，供应商禁止自动回退。

## 执行与恢复

- 使用原始冻结清单和视频，保持原题目、参考答案与来源说明。缺少翻包验证补充时停止，
  不回退到 validation24，不从模型预测重建标签。
- 固定 1 FPS、共享 720px JPEG、12 个队列槽。API / CLIP / SigLIP2 使用单帧；
  VideoJev / Decision3 保留相邻两帧窗口及各自原生精度。
- 每个请求单元累计最多三次尝试；保留首次有效回答。恢复时先核对原始响应、结果和账本，
  不因进程重启重新发送已有有效回答，不清零未知费用或中断请求。
- 一道题须具备所有计划响应。完整证据下：任一 yes → yes；否则任一 no → no；
  否则 unknown。缺失与最终 unknown 留在准确率分母中，分别报告。
- Luna、CLIP、SigLIP2 在完整 validation44 上选择六类阈值并冻结后再测试。
  布尔和原生 argmax 模型不新增数值阈值。
- 模型与轮次顺序执行。恢复使用相同配置、代码、数据、硬件、凭据身份和原始截止时间。
  失败轮次保留，不补第十一轮掩盖失败。
- 监督进程通过生命期管道检测主控退出，终止本次拥有的工作进程组，释放锁后才允许恢复。
  后台模式要求网络与凭据不依赖当前交互命令的生命期。

## 预算与部署边界

十轮批次按全部请求最多三次尝试预留费用上界。验证模式可选逐请求滚动预留：
发送 intent 前原子预留完整单次上界，只在持久化结果包含有限实测费用后释放余额。
未知费用保留完整预留；超过计价上界时停止后续请求。

滚动预留可设置最长 120 秒、且短于无进展超时的等待期。只等待本工作进程正在执行的
请求返回费用证据；历史中断请求和已完成但费用未知的请求不会被当作待返回请求。
等待不持有准入锁，也不计入模型请求延迟。STOP 文件或队列取消会阻止新的请求意图。

GPU 路线要求预先准备并独立管理的主机 / 服务；每阶段开始前核对硬件指纹。
本控制器不租机、不恢复 R2 环境、不释放远端租约。资源归属或独立到期清理措施、
实际部署和新增预算必须落实后才能执行。

## 验证与交付

相关离线测试覆盖数据扩展、阈值阶段顺序、请求身份、费用预留、中断恢复、
进程监督和十轮统计。测试使用合成数据，不证明某个实时 GPU / API 部署已经可用。
PR 描述记录本次提交实际通过的回归范围与数量。

输出包含逐轮 JSON / CSV、正确率、覆盖率、缺失、P50/P95、重启和费用证据，
以及均值、样本标准差和范围。十轮 P95 的统计不是全部请求合并后的 P95；
12 个队列槽不证明可实时处理 12 路摄像头。

模型测评结果、私有视频 / 抽帧、标签清单、凭据、主机地址和逐请求账本保留在各自私有
运行目录，不属于源代码 PR。准备好的快照在代码改变后须使用原快照源码重放，
或为新执行重新生成快照；不能修改历史快照的哈希来通过校验。
