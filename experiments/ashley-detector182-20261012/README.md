## 固定答题方法

- 每款同182题。90题仅依赖几何记录：36计数、44位置、10人数时间，关闭VLM。92题保留事件VLM：66事件、26动作／冲突时间。
- 每款先行20题，名单按公开元数据固定，计入182；不按成绩挑题或重复先行结果。
- 原生51词表、事件生命周期、parser和确定性提取沿用；事件观察使用 Qwen3-VL-8B，窗口不读取题目，公开事件标签用于会话功能选择。无最终总结LLM。
- 计数、位置与人数时间由人物框、ID和时间戳计算；事件与动作时间由原生确认状态、episode及对应提取规则生成答案。无法确定唯一选项时可能保存空答；中断或未完成保留 pending。
- 检测器真实来源、权重SHA256和CUDA设备随记录保存。observed与predicted轨迹分开，空帧保留；自然EOF、同会话tracking排空和几何完成标记用于确认执行完整性。
- 新对照使用 Benchmark PR63 的公开信息评分。旧答案离线重评分另存，原分保留；私有GT仅用于本地评分。
- 成功缓存要求完整请求与图片等输入一致；未知请求保持封锁，同输入跨轮最多3次。模型已知费用20美元、GPU实际已知费用10美元，累计不随恢复清零，缺账单费用单列。正式启动24小时截止不因恢复延长。
